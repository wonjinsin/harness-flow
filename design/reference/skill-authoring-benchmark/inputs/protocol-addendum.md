# Pre-holdout protocol additions and operational deviations

These additions were recorded before any held-out consumer outcomes were observed. Frozen source policy and held-out cases are unchanged.

- Add a `raw-procedure` consumer control: supply the relevant uncompressed subject section from the source packet, with no authoring transformation. This distinguishes knowledge supplied by any artifact from value added by an authoring method. Together with six authored arms and the no-skill control, the common held-out track contains 8 conditions × 2 subjects × 5 cases × 5 trials = 400 calls.
- Add a separate metadata-only selection probe for the six authored common-track arms: four fixed prompts (release review, incident handoff, release marketing copy, general HTTP explanation), five fresh trials per prompt. This is 120 calls. The prompt-based selector is not a native harness activation test.
- The ECC source history is an actual six-commit synthetic Git fixture created in a new temporary repository; it is not production history. Its portable bundle and observed model records are retained. No existing source repository was committed. The protocol's prohibition on publication commits does not describe these isolated fixture-history objects.
- Native gstack authoring uses actual local-page navigation and DOM extraction through the available Chromium browser tool, mapped to the source method's browser operations. No native gstack browse binary or dependencies were installed in the upstream checkout. Generated scripts will be run through the unchanged canonical SDK and a real-browser HTTP adapter supporting goto/html. The adapter supplies real navigations and DOM, not canned output, but does not validate the native daemon's authentication, scopes, discovery, or installation.
- Native gstack creates two products in two fresh subject-specific author contexts; common methods create both products in one author context. Heterogeneous tracks are not combined or ranked.
- Several author arms reported incidental exposure to the local writing-skills wrapper due mandatory harness routing. Preserve these disclosures. Treatment isolation is therefore imperfect, even when an agent says it followed only its assigned method.
- The shared authoring brief explicitly offers development cases, baseline evidence, complete interfaces, and a probe tool. This scaffolding also helps the unaided control. It tests the incremental effect of authoring guidance over a strong brief, not unconstrained author skill discovery.
- A tool registration failure required a Python 3.9 compatibility shim for the Eval helper's UnionType inspection. A browser HTML helper required an explicit `html` selector. Both are infrastructure deviations, not model or generated-artifact failures.
